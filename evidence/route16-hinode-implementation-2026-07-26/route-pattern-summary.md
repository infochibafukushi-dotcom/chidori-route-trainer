## 往路・復路の関係

- 停留所名の並びは **完全な逆順**（10停留所、経由地の増減なし）。
- ただし **道路は別relation**（18396563 / 18396562）であり、往路pathの反転による復路生成は禁止。
- のりばのノードIDと座標は往復で別。新浦安駅は往路 `platform_entry_only` / 復路 `platform_exit_only`、
  日の出七丁目は往路 `platform_exit_only` / 復路 `platform_entry_only`。
- 復路の凡例は「プラウド新浦安パークマリーナ・**海風の街**経由 新浦安駅行き」で、海風の街は往復とも経由する。

## 16系統と17系統の切り分け（最重要）

| | 16系統 | 17系統 |
| --- | --- | --- |
| 路線名 | 日の出線 | 日の出線（同名） |
| 新浦安駅 のりば | C | 17 |
| 符号 | 無印 | ベ / ★ベ（深夜バス） |
| 経由 | プラウド新浦安パークマリーナ・海風の街 | 日の出東・東京電力 |
| 固有の停留所 | 海風の街 | 日の出保育園入口 / 東京電力 / 日の出小学校 / 日の出東 / アールフォーラム / 順天堂大学・日の出 東口 |
| OSM relation | 18396563 / 18396562 | 18396568 / 18396569 / 18396583 |

両系統とも 日の出七丁目 を発着し、日の出西・順天堂大学・日の出 正門・プラウド新浦安パークマリーナ・
日の出中学校・ベイシティ浦安 を共有するため、**コース名や中間停留所ののりばでは分離できない**。
出発停留所ののりば凡例まで遡って初めて系統が一意に決まる。
